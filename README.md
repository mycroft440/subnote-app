# SubNote 📝

App de notas com **subnotas inline** que se expandem e o texto circunda ao redor.

## Features

- ✨ **Subnotas Inline** - Insira subnotas que aparecem como botões no texto
- 📐 **Texto Circundante** - Ao expandir, o texto flui ao redor da subnota (CSS float)
- 🔄 **Expandir/Minimizar** - Clique no botão para expandir, minimize para voltar ao normal
- 📋 **Lista de Subnotas** - Veja todas as subnotas em ordem alfabética ou numérica
- 💾 **Auto-Save** - Salvamento automático via LocalStorage
- 🌙 **Dark Theme Premium** - Interface moderna com glassmorphism e animações

## Como Usar

1. Abra `index.html` no navegador
2. Clique em **+** para criar uma nota
3. Escreva seu texto
4. Use **Inserir Subnota** para adicionar subnotas inline
5. Clique no botão da subnota para expandir
6. Use **Ver Subnotas** para lista completa

## Tech Stack

- HTML5 / CSS3 / JavaScript (Vanilla)
- Sem dependências externas
- PWA-ready mobile-first design
